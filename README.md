## Описание проекта

Данный проект содержит фронтенд-страницы, бекенд на .NET, практические задания по командной строке, а также пример документации в Markdown. Цель — закрепить навыки работы с Git, структурой проекта, Markdown, терминалом и LaTeX.

---
## Содержание

- Структура проекта
- Frontend: HTML-страницы
- Backend: консольное приложение
- Практика терминала
- Документация Markdown
- Основные команды Git
- Скриншоты
